# Google AI Chat Exporter (Google AI 聊天导出工具) 🚀

这是一个轻量级、零资源消耗的小书签（Bookmarklet），只需一键即可导出您与 Google AI (AI Search/Gemini) 的完整聊天记录。

与官方导出工具不同，此脚本会按**时间顺序导出整个对话**（包括您的提示词和 AI 的回复），并将其保存为干净的 Markdown (`.md`) 和/或文本 (`.txt`) 文件。

## 功能特点
- **零后台资源消耗：** 它只是一个小书签，而不是浏览器扩展插件。
- **智能格式化：** 保持所有 HTML 结构（粗体、列表、代码块、链接）完整，并将其转换为纯 Markdown。
- **清理无用信息：** 自动删除 UI 按钮（“复制”、“编辑”、“分享”）、系统警告和多余的界面元素。
- **自定义导出：** 允许您命名文件并选择所需的格式（`.md`、`.txt` 或两者都要）。
- **时间戳：** 自动在文件名后附加当前日期和时间。

## 安装说明 (1分钟搞定)
1. 在浏览器中按 `Ctrl + D`（Mac 上为 `Cmd + D`）在任意页面创建一个新书签。
2. 点击 **更多...** 或 **编辑** 来修改书签详情。
3. 在 **名称** 字段中，输入类似 `📥 导出 AI 聊天` 的名称。
4. 在 **URL（网址）** 字段中，复制并粘贴 [此处的完整 JavaScript 代码](https://raw.githubusercontent.com/ТВОЙ_GITHUB/ТУТ_ССЫЛКА_НА_КОД)。
5. 保存并将其放在您的书签栏上。

## 如何使用
1. 打开您与 Google AI 的聊天页面。
2. 向上滚动到顶部（确保整个聊天已在浏览器中加载）。
3. 点击您新建的 `📥 导出 AI 聊天` 书签。
4. 在弹出的窗口中输入文件名称。
5. 选择您需要的格式（1 = `.md`, 2 = `.txt`, 3 = 两种格式）。
6. 完成！文件将下载到您的电脑中。

## 隐私与安全
该脚本完全在您的浏览器本地运行。它不会将您的任何聊天数据发送到任何外部服务器。

## 提示：
如果您使用的是 Google Pro 订阅或在 Chrome 侧边栏中打开聊天窗口，脚本可能无法运行或返回“找不到 AI 回复”的错误。

这是由于浏览器的系统保护机制导致的。

解决方法：点击“分享”-> 复制聊天链接，然后在隐身模式下打开。脚本即可完美运行！
